# AI味评分系统使用指南

> 为小说正文提供 **0-10 分** 的 AI 味量化评分。
> 10 分 = 完全看不出 AI / 0 分 = 100% AI 生成。

---

## 评分维度

### 维度一：显性AI味（高AI率）

**一眼就能看出的 AI 痕迹。** 权重最高（45%）。

| 检测项 | 示例 | 单次扣分 |
|--------|------|----------|
| 机械对比句式 | 不是害怕，而是不安 | -3.0 |
| 机械对比句式 | 不像愤怒，而像失望 | -3.0 |
| 排比否定 | 没有哭，也没有闹 | -2.5 |
| 填充词 | 他不知道该怎么开口 | -2.0 |
| 不由得/下意识 | 不由得后退一步 | -1.5 |
| 情绪标签直贴 | 他感到十分烦躁 | -1.0 |
| 物件当主语 | 空气里弥漫着紧张 | -1.0 |
| 说明腔动作 | 她将杯子放置在桌面之上 | -1.0 |

### 维度二：结构性AI味（中AI率）

**读几段后能察觉的结构模式。** 权重 30%。

| 检测项 | 阈值 | 单次扣分 |
|--------|------|----------|
| 连接词密度 | > 3% | ~0.8/超出% |
| 解释腔（抽象判断词） | ≥ 2 次 | 0.8/次 |
| 比喻堆叠 | ≥ 3 次 | 1.0/超出 |
| 多句号段落 | ≥ 2 个句号/段 | 0.5/超出 |

### 维度三：隐性AI味（低AI率）

**细细品味才会察觉的微妙痕迹。** 权重 25%。

| 检测项 | 阈值 | 单次扣分 |
|--------|------|----------|
| 虚化词密度 | > 2% | ~0.5/超出% |
| 抽象词密度 | > 3% | ~0.4/超出% |
| 「的」密度 | > 6% | ~0.3/超出% |
| 句长均匀度 | CV < 0.2 | ~1.0-2.0 |

---

## 评分等级

| 分数 | 等级 | 含义 |
|------|------|------|
| 9.0-10 | **S** | 几乎无AI味，像真人写作 |
| 8.0-8.9 | **A** | 仅有少量AI味，整体自然 |
| 7.0-7.9 | **B** | 轻微AI味，细读可察觉 |
| 6.0-6.9 | **C** | 中等AI味，建议改进 |
| 4.0-5.9 | **D** | 明显AI味，必须修改 |
| 2.0-3.9 | **E** | 严重AI味，需大幅重写 |
| 0.0-1.9 | **F** | 纯AI腔，建议完全重写 |

## 使用方式

### 1. 独立评分

```bash
# 对章节评分
python3 scripts/ai_scoring.py <project-dir> <chapter-id>

# JSON 输出（供脚本调用）
python3 scripts/ai_scoring.py <project-dir> <chapter-id> --json

# 指定输出路径
python3 scripts/ai_scoring.py <project-dir> <chapter-id> -o report.md
```

### 2. 去AI味对比

```bash
# 先跑 humanize_pass 生成去AI味稿
python3 scripts/humanize_pass.py <project-dir> <chapter-id>

# 然后用 ai_scoring 对比原始 vs 去AI味后
python3 scripts/ai_scoring.py <project-dir> <chapter-id> \
  --compare .novel-studio/logs/<chapter-id>-humanize-pass.md
```

### 3. humanize_pass 内置评分

`humanize_pass.py` 已集成评分——每次运行自动输出去AI味前后对比：

```
## 🎯 AI味评分（去AI味前后对比）

| 状态 | 综合分 | 显性AI味 | 结构性AI味 | 隐性AI味 | 等级 |
|------|--------|----------|------------|----------|------|
| 去AI味前 | 8.5/10 | 8.6 | 7.5 | 9.4 | A |
| 去AI味后 | 9.0/10 | 8.9 | 8.5 | 9.7 | S |
| 📈 提升 | +0.5 | +0.3 | +1.0 | +0.3 | — |
```

### 4. 作为 Python 模块

```python
from ai_scoring import score_full, quick_score, compare_scores

# 快速评分
score = quick_score(chapter_text)  # 返回 float

# 完整评分报告
report = score_full(chapter_text, source_label="第10章")

# 去AI味前后对比
comparison = compare_scores(before_text, after_text)
# → {"before": 7.2, "after": 8.5, "delta": 1.3, "improved": True, ...}
```

## 与 humanize 风格指南的关系

| 评分维度 | 对应 humanize 规则 |
|----------|-------------------|
| 显性AI味 | 对比句式、填充词、情绪标签、物件主语、说明腔（黑名单1/2/3/6/7） |
| 结构性AI味 | 连接词、比喻堆叠、多句号段落、解释腔（原则3/5/10 + 黑名单4/8） |
| 隐性AI味 | 虚化词、抽象词、句式匀称度（原则4/5 + 黑名单5） |

---

## 设计原则

1. **惩罚制而非加分制**：起始满分 10 分，发现问题扣分
2. **显性优先**：一眼能看出的问题（对比句式、填充词）扣分更多
3. **密度敏感**：不是绝对数量，而是密度超标才扣分
4. **分段独立**：每段独立评分，综合分取平均
5. **保守设计**：宁可松一点，不冤枉好文字
